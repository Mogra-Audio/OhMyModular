The first public release of OhMyModular: a small collection of VCV Rack modules
built around a real-time double pendulum.

## Modules

### OhMyPendulum (11 HP)

A chaotic CV generator driven by a double pendulum simulated with RK4 at audio
rate. Two coupled arms produce smooth and discrete angle outputs for each arm.
The Chaos control runs a second, virtual pendulum in the background; turning it
down starts an energy servo that returns the system to its pre-chaos energy.

- 5 knobs: Angle I, Angle II, Time, Skew, Chaos
- 2 inputs: Retrigger, Chaos CV
- 4 outputs: Angle I Smooth, Angle I Discrete, Angle II Discrete, Angle II Smooth
- 5 themes: Mono, Creme, Minty, Mage, Love

### OhMyPendulum Expander (6 HP)

Attaches to the right of OhMyPendulum and adds:

- Time CV and Skew CV inputs (0–10 V absolute override; the matching knob is
  locked while a cable is patched)
- Four XY outputs: elbow X/Y and tip X/Y (±2.5 V / ±5 V)
- Automatic theme inheritance from the main module

## Installation

OhMyModular is not in the VCV Library yet. Download the `.vcvplugin` for your
platform from the assets below and place it in the Rack 2 user plugins
directory:

| Platform | Directory |
| --- | --- |
| macOS (Apple Silicon) | `~/Library/Application Support/Rack2/plugins-mac-arm64/` |
| macOS (Intel) | `~/Library/Application Support/Rack2/plugins-mac-x64/` |
| Windows | `%LOCALAPPDATA%\Rack2\plugins-win-x64\` |
| Linux | `~/.local/share/Rack2/plugins-linux-x64/` |

Close Rack, copy the file, and start Rack again.

## Requirements

- VCV Rack 2.0 or newer (built against Rack SDK 2.6.6)
- macOS 10.9+, Windows 7+, or Linux x64
- The modules are monophonic; polyphonic cables are not supported.

## Notes

- The expander only works when placed directly to the right of OhMyPendulum.
- Loading a patch resets the pendulum from the Angle knobs. Patches store the
  initial conditions, not the live pendulum state.
- The main angle outputs are slew-limited. The expander's XY outputs are not:
  they follow the true position, which is what an XY display should show.
- Chaos is deterministic, not a random source.
